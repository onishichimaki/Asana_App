# 本番受入テスト

実行日、担当者、対象URL、端末名を記録し、すべて成功してから利用者へ案内する。

## 共通

- [ ] 会社メールへ確認コードが届き、ログイン・ログアウトできる
- [ ] 別ドメインのメールが拒否される
- [ ] 同じ会社メールのAsanaアカウントだけ接続できる
- [ ] 異なるメールのAsanaアカウントが拒否される
- [ ] 接続したAsanaで見られるプロジェクトだけが表示される
- [ ] テキスト整理、修正、親・サブタスク登録、履歴表示が成功する
- [ ] Excel・CSVの列を変更してマッピング、確認、一括登録、再送防止が成功する

## iPhone / iPad

- [ ] HTTPS URLをSafariで開き、横スクロールが発生しない
- [ ] 音声入力、貼り付け、カメラ撮影、日本語OCRが成功する
- [ ] 30件以上のWBSをカード表示で確認・検索・登録できる
- [ ] 画面を閉じて再度開いても有効期間内のログインが維持される

## Windowsランチャー

- [ ] 起動時に右下へ表示され、通常入力がスクロールなしで完了する
- [ ] Ctrl+Shift+A、クリップボード取込、登録後自動非表示が成功する
- [ ] 一括登録で画面が拡大し、Excelファイルを選択できる
- [ ] タスクトレイ、単一起動、Windowsログイン時自動起動が成功する

## 運用

- [ ] `scripts/Test-TaskCaptureReadiness.ps1` が `TASK_CAPTURE_READY=true` を返す
- [ ] SQLバックアップを作成し、`RESTORE VERIFYONLY` が成功する
- [ ] Data Protection鍵とSQLバックアップを別の安全な場所へ複製する
- [ ] API停止・ready失敗時の監視通知先を確認する
